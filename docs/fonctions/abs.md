# `abs`

*Français · [English](abs.en.md)*

Valeur absolue d'un nombre (null si ce n'est pas un nombre)

```
abs(token)
```

**Exemple**

```jslt
{ "r": abs($.n) }
```

```json
{ "n": -3.5 }
```

```json
{ "r": 3.5 }
```
