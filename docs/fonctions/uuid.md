# `uuid`

*Français · [English](uuid.en.md)*

Nouvel identifiant unique aléatoire (UUID v4) à chaque appel

```
uuid()
```

**Exemple**

```jslt
{ "r": stringlenght(uuid()) }
```

```json
{}
```

```json
{ "r": 36 }
```

Cette fonction ne prend aucun argument.
