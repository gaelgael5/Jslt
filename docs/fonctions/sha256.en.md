# `sha256`

*[Français](sha256.md) · English*

SHA-256 digest of a value, in hexadecimal

```
sha256(token)
```

**Example**

```jslt
{ "r": sha256($.t) }
```

```json
{ "t": "abc" }
```

```json
{ "r": "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad" }
```

| Parameter | Expected | Note |
|---|---|---|
| `token` | optional |  |

**Good to know**

- For **identity** (comparing, indexing), never for signing: concatenating a secret and a message before a `sha256` exposes you to length extension. To sign, use `hmacsha256`.
