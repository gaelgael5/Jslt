# `exp`

*[Français](exp.md) · English*

Exponential: e raised to the power of the number

```
exp(token)
```

**Example**

```jslt
{ "r": round(exp($.n), 3) }
```

```json
{ "n": 1 }
```

```json
{ "r": 2.718 }
```
