# `logarithm2`

*Français · [English](logarithm2.en.md)*

Logarithme binaire (base 2) d'un nombre

```
logarithm2(token)
```

**Exemple**

```jslt
{ "r": logarithm2($.n) }
```

```json
{ "n": 8 }
```

```json
{ "r": 3.0 }
```
