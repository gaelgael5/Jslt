# `sha256`

*Français · [English](sha256.en.md)*

Empreinte SHA-256 d'une valeur, en hexadécimal

```
sha256(token)
```

**Exemple**

```jslt
{ "r": sha256($.t) }
```

```json
{ "t": "abc" }
```

```json
{ "r": "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad" }
```

| Paramètre | Attendu | Note |
|---|---|---|
| `token` | optionnel |  |

**À savoir**

- Pour l'**identité** (comparer, indexer), jamais pour signer : concaténer un secret et un message avant un `sha256` expose à l'extension de longueur. Pour signer, `hmacsha256`.
