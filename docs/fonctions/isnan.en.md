# `isnan`

*[Français](isnan.md) · English*

True when the value is the undefined result of a computation (NaN)

```
isnan(token)
```

**Example**

```jslt
{ "r": isnan($.n) }
```

```json
{ "n": 3 }
```

```json
{ "r": false }
```
