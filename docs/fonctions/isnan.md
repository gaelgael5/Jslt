# `isnan`

*Français · [English](isnan.en.md)*

Vrai si la valeur est le résultat indéfini d'un calcul (NaN)

```
isnan(token)
```

**Exemple**

```jslt
{ "r": isnan($.n) }
```

```json
{ "n": 3 }
```

```json
{ "r": false }
```
