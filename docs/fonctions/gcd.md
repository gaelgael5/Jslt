# `gcd`

*Français · [English](gcd.en.md)*

Plus grand commun diviseur de deux entiers

```
gcd(left, right)
```

**Exemple**

```jslt
{ "r": gcd($.a, $.b) }
```

```json
{ "a": 84, "b": 36 }
```

```json
{ "r": 12 }
```
