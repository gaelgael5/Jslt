# `stringlenght`

*[Français](stringlenght.md) · English*

Number of characters of a text — original, misspelled name kept: see stringlength

```
stringlenght(token)
```

**Example**

```jslt
{ "r": stringlenght($.t) }
```

```json
{ "t": "bonjour" }
```

```json
{ "r": 7 }
```
