# `isuuid`

*Français · [English](isuuid.en.md)*

Vrai si le texte a la forme d'un UUID (accolades tolérées)

```
isuuid(token)
```

**Exemple**

```jslt
{ "r": isuuid(uuid()) }
```

```json
{}
```

```json
{ "r": true }
```
