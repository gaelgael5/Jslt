# `logarithm`

*Français · [English](logarithm.en.md)*

Logarithme népérien (base e) d'un nombre

```
logarithm(token)
```

**Exemple**

```jslt
{ "r": logarithm($.n) }
```

```json
{ "n": 1 }
```

